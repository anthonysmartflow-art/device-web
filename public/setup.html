deviceweb

One setup. All your websites.

Connect scrolling across your previews with the Device Web browser helper. Install it once in Chrome or Edge, then use your existing and future Vercel sites.

Download browser helper ↓
  1. Download and unzip the helper.Keep the unzipped folder somewhere permanent on your computer.
  2. Open your browser’s extensions page.In Chrome, enter chrome://extensions in the address bar. In Edge, enter edge://extensions. Turn on Developer mode.
  3. Choose “Load unpacked” and select the helper folder.Select the folder containing manifest.json. Reopen Device Web in that browser, load your website, and keep All devices selected.

What to expect

The caption says Scroll linked across all devices when the connection is ready. Scrolling any device moves the others to the same percentage down the page.

The extension requests access to HTTPS pages so it works with new project URLs. It activates only in website frames directly inside Device Web. It sends no data to a server and does not change your website’s code.

Use Chrome or Edge on a computer. Installing it in Chrome does not add it to Safari or the Codex in-app browser. Sites with the built-in helper work without the extension.

Websites must still allow embedding. The helper cannot bypass sign-in or security restrictions. It links the main page’s scrolling; independently scrolling menus and panels are excluded.
